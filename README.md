# StudioSpace Client

**StudioSpace** is a creative studio booking platform where users can explore studio spaces, view studio details, and book their preferred studios.

## 🌐 Project Links

| Type | Link |
|---|---|
| 🌍 Live Website | [StudioSpace Live Demo](https://studiospace-client-beige.vercel.app/) |
| 💻 Frontend Repository | [StudioSpace Client](https://github.com/Gyanadewan/studioSpace-client) |
| ⚙️ Backend Repository | [StudioSpace Server](https://github.com/Gyanadewan/studioSpace-server) |

## 🚀 Technologies Used

- Next.js 16
- React 19
- JavaScript (ES6+)
- Tailwind CSS 4
- DaisyUI
- shadcn/ui
- Better Auth
- MongoDB
- Lucide React
- React Icons
- React Toastify
- Swiper.js

## ✨ Features

- Responsive and modern user interface
- Browse and explore studio spaces
- Filter studios by category
- View detailed studio information
- User authentication with Better Auth
- Secure customer booking system
- Manage personal bookings
- Protected routes using authentication
- Interactive image sliders
- Toast notifications
- Modern UI components

## 🔐 Authentication

- Better Auth for user authentication
- JWT-based authentication
- Protected routes using authentication sessions
- MongoDB integration for user data
